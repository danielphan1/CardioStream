## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug in verification tooling] Corrected an overly strict mid-close opacity assertion in the Task 2 live-verification script**
- **Found during:** Task 2 (initial run of the Playwright verification script)
- **Issue:** The script's first draft asserted the region's computed `opacity` must read strictly `<1` immediately after the Close click, as a standalone pass/fail check separate from the "region still present in the DOM" check. In practice, the browser had not yet applied the class change/repainted at the instant the script read `getComputedStyle` (a single-threaded JS tick before the next paint), so `opacity` still read `"1"` even though the region was correctly still mounted and about to fade. This produced a false-positive failure that contradicted the plan's own documented acceptance criterion for this step: "opacity <1 shortly after the click (mid-fade) OR ... the element should still at minimum still be present in the DOM at that instant"
- **Fix:** Rewrote the check as a single combined OR condition (`opacity !== "1" || count > 0`) matching the plan's own documented acceptance wording, rather than two independent required checks
- **Files modified:** none in the repo (scratch `verify.mjs` in `/private/tmp/.../scratchpad/ly8-01-verify/pw/`, deleted after use)
- **Verification:** Re-ran the script after the fix — all 8 checks passed (entrance fade to opacity 1 for both backdrop and region, region present immediately after Close, close-transition-in-progress OR-check, region removed within ~500ms, Escape closes + region removed within ~500ms, focus restored to `#guide-toggle-button` promptly, reduced-motion path still reaches opacity 1)
- **Committed in:** N/A (scratch tooling, not committed)

- `npm install --no-save playwright` in a bare scratch directory with no `package.json` silently resolved as a no-op ("up to date", nothing installed) — npm walks up the directory tree looking for the nearest `package.json` when none exists locally, and with `--no-save` it apparently treated an ancestor's `node_modules` as already satisfying the request without installing anything locally. Fixed by running `npm init -y` first to create a local `package.json` before `npm install --no-save playwright`, which installed correctly (v1.62.1) into the scratch directory's own `node_modules`.
