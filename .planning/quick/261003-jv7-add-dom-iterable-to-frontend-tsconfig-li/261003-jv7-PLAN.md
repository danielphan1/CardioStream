# Quick 261003-jv7: DOM.Iterable in the frontend tsconfig lib

The Vercel production build for `8b70bee` failed on both Vercel projects
(`health-dashboard` and `health-dashboard-demo`) at 21:08 UTC today. Railway
succeeded, so the backend is current and only the frontend is stale — the last
green frontend deploy is `e3f6b05` from 2026-09-19.

## Root cause

`frontend/package.json` runs `tsc -b && vite build`, and `tsc -b` fails:

```
src/components/charts/CombinedTimelineCompact.test.tsx(113,7): error TS2488:
  Type 'NodeListOf<SVGRectElement>' must have a '[Symbol.iterator]()' method
  that returns an iterator.                        (same at 130,23 and 141,23)
```

`tsconfig.app.json:5` declares `"lib": ["ES2023", "DOM"]`. `DOM` alone types
`NodeList` without `[Symbol.iterator]`; the iterator declarations live in
`DOM.Iterable`, which the Vite `react-ts` template ships by default and this
config is missing. The three `[...container.querySelectorAll(...)]` spreads in
the test file added by `3f1006a` are the first code in the repo to need them.

`include: ["src"]` covers test files, so a test-only type error kills the
production build. Nothing catches this locally: `vitest` and `vite dev` strip
types without checking them, and `npm run build` was not run before the push.

## Task 1 — add DOM.Iterable

Edit `frontend/tsconfig.app.json`: `"lib": ["ES2023", "DOM", "DOM.Iterable"]`.

No source changes. `target: es2023` already emits native spread, so this only
supplies the missing type declarations — zero runtime effect.
