  <action>Create `scripts/smoke.sh` (executable, `set -euo pipefail`). Read `BASE` (the Railway URL) and `SITE_PASSWORD` from env (the script must never hardcode the secret). Curl each gated route using its REAL HTTP method WITHOUT a token and assert the HTTP code is `401`, failing loudly with the method+path and actual code otherwise: `GET $BASE/readings`, `GET $BASE/stats/summary`, `POST $BASE/agent`, `POST $BASE/upload`. Use each route's real method because `verify_token` is a router-level dependency, not middleware — Starlette returns 405 Method Not Allowed on a method mismatch BEFORE `verify_token` runs, so a POST to the GET-only `/readings` or `/stats/summary` would return 405, not 401. Curling each route with its actual method proves the auth gate fires on the method the route really serves (SC2's "curl-verified" 401-on-every-route). Then: POST `/auth` with a wrong password and assert 401; POST `/auth` with `$SITE_PASSWORD` and capture the `token` from the JSON; GET `/readings` with `Authorization: Bearer $token` and assert 200. Print `PASS` and exit 0 on success; exit non-zero on any assertion failure. Add a header comment documenting usage: `BASE=https://<app>.railway.app SITE_PASSWORD=... bash scripts/smoke.sh`. Log no secret values (never echo the password or token).</action>
