<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| recognizer events → hook state | Browser-authored `onresult`/`onerror` payloads drive the hook; only `extractCommand`-gated strings become commands, only closed-union replies touch the store |
| voice command string → /agent | Untrusted transcript crosses to the backend via the SAME `postAgent` the text box uses; bounded + Pydantic-validated server-side (Phase 3) |
| stale in-flight reply → filter store | A superseded command's late `onSuccess` must not mutate the single-surface store |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | onresult → mutate | mitigate | Hook sends only `extractCommand` output as a plain string; never builds `AppliedFilters` from raw speech. Server structured-outputs validation is the authority. |
| T-04-02 | Tampering / EoP | spoken prompt-injection | mitigate | Even a hostile transcript can only yield a valid closed-union `AgentOutput`; ranges clamped server-side; descriptive-only agent (VOICE-09). Hook executes nothing model-authored. |
| T-04-03 | DoS / cost | rapid commands + restart loop | mitigate | `computeBackoff` caps restart frequency (no request storm); seq guard drops redundant/superseded applies; server `text` length cap + 429 handling already enforced. |
| T-04-04 | Info Disclosure | errors / transcript in logs or UI | mitigate | `onError`/`enterPaused` surface only fixed friendly copy (RATE_LIMIT/OFFLINE/D-14) — raw `e.error`/`ApiError` never rendered (VOICE-07); no `console.log` of transcripts (SEC-03). |
| T-04-05 | Info Disclosure | always-hot mic | mitigate | Explicit-stop-only session (D-13) with a visible LISTENING state (surfaced in Wave 3); `stop()` aborts the recognizer; no background listening (visibility guard pauses when hidden). |
</threat_model>
