Replace the 588px stat-card block with the ~90px inline vitals strip (UI-SPEC §5.6) and delete the sparkline it made dead.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `/stats/summary` payload → rendered readouts | Every number in the strip comes straight from the backend-computed payload. No client-side arithmetic over readings happens here, per the Architectural Responsibility Map — so the strip cannot disagree with the API, and dropping the `readings` prop strengthens that by removing the only raw-series input the component had. |
| rendered value → a clinical reading of it | A health figure that renders `0` where the real answer is "no data" is a clinical misstatement. The D-22 null contract is the control on that boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16.1-34 | Spoofing | null vitals rendering as `0` | mitigate | The D-22 null contract is enforced by the new test file: a null `VitalStats` must render `—` for the value and "minimum and maximum unavailable" for the range, and the test asserts `0` never appears |
| T-16.1-35 | Tampering | removing the `readings` prop | mitigate | `StatsStrip` never derived anything from the raw series except the retired sparkline and the retired status pill; dropping the prop removes the only path by which the strip could ever disagree with the API's own computed figures |
| T-16.1-36 | Information Disclosure | shortening the visible range string | accept | Nothing is lost: the sr-only span preserves the min/max words verbatim, so a screen-reader user hears strictly more than the en-dash range shows, and the test asserts both spans |
| T-16.1-37 | Denial of Service | a four-column phone layout forcing horizontal scroll | mitigate | `grid-cols-2` with `lg:grid-cols-4` is grep-asserted, so the No-Off-Screen Rule holds at 375px without shrinking type below the 18px floor |
| T-16.1-38 | Tampering | npm/pip/cargo installs | mitigate | Not applicable: no dependency is added, and this plan removes one component without adding any |
</threat_model>
