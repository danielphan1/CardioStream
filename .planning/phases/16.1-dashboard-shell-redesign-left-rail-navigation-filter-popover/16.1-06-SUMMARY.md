# Phase 16.1 Plan 06: Mount the Shell Summary

**The 216px horizontal header band stops existing: one `AppShell` in `App.tsx` mounts the left rail above 1024px or the slim bar + nav panel below it, holds a single `openOverlay` state with bidirectional guide exclusion, measures one never-`inert` top band for every panel's offset, and carries the deleted wrapper's `inert={guideOpen}` onto the rail — with `Header.tsx` retired and seven now-false strings repointed at the menu.**

## Accomplishments

- **`AppShell` replaces three duplicated per-view blocks.** `Dashboard`, `UploadView` and `RecordsView` (and `readings`, which still falls through to `Dashboard` until plan 16.1-09) all route through one wrapper. Gone: the three `<div inert={guideOpen} ref={headerRef}><Header /></div>` blocks, the three `headerRef`/`commandBarRef` pairs, and the three separate `useClearanceHeight` calls.
- **The `inert` reassignment landed on the rail.** `{isDesktop && <LeftRail inert={guideOpen} />}` — grep-gated to exactly one bare `inert={guideOpen}` in the file. Without it, Tab would walk a keyboard or switch-access user through eight invisible, unusable controls (the guide's backdrop covers the rail completely, since the rail deliberately has no stacking offset) before reaching the Command Bar.
- **Guide exclusion runs in both directions.** `useEffect(() => { if (guideOpen) setOpenOverlay(null); }, [guideOpen])` — one effect covering the slim bar, the rail and `lib/agent.ts`'s voice path, rather than three scattered handlers. Opening the nav panel closes the guide in `toggleNav`.
- **One measured band, never `inert`.** `<div ref={shellTopRef}>` wraps the slim bar and the Command Bar, goes `sticky top-0 z-[60]` while `anyOverlayOpen`, and its single `useClearanceHeight(shellTopRef)` result feeds both `GuideOverlay`'s `clearanceAbove` and `NavPanel`'s `top`. The mic stays reachable with any overlay open (D-03/D-04).
- **`data-surface="panel"` on the Command Bar section** activates the `--color-signal-on-panel` token plan 16.1-02 shipped dormant, closing a pre-existing 2.90:1 focus-ring gap.
- **`Header.tsx` and `Header.test.tsx` deleted** after confirming all five of the old suite's assertions have live homes (verified by running those three files green before the delete, 33 tests).
- **Seven strings repointed.** The agent-unavailable banner names the menu; four guide sections say "in the menu"; the Filters section describes the trigger-and-panel flow; the Charts section names the View buttons (stale since Phase 14). `OFFLINE_COPY` deliberately untouched.
- **The `<1024px` Guide path is now unit-tested**, not browser-only: jsdom has no `matchMedia`, so `isDesktop` is false and the slim-bar shell is what mounts under test.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing Critical] Removed the nested `<main>` landmarks in `UploadPage` and `AddRecordPage`**

- **Found during:** Task 1 (AppShell)
- **Issue:** The plan has `AppShell` render `<main inert={…}>{children}</main>` and has `UploadView`/`RecordsView` pass `<UploadPage />` / `<AddRecordPage />` "bare". Both of those pages already declared their own root `<main>` (`UploadPage.tsx:86`, `AddRecordPage.tsx:177`) — today that is the view's only `<main>`, but under `AppShell` it becomes a `<main>` nested inside a `<main>`. That is invalid HTML and hands assistive tech two main landmarks on the two caregiver surfaces, against CLAUDE.md's non-negotiable accessibility floor. The plan did not list these two files in `files_modified`, so it had not spotted it.
- **Fix:** Changed both roots from `<main>` to `<div>`, keeping every class byte-identical, with a three-line comment on each stating that `AppShell` owns the single landmark so nobody re-adds it. `AppShell`'s `<main>` is now the app's only one in the authed tree (`LoginGate`'s is on the pre-auth surface and never co-renders).
- **Files modified:** `frontend/src/components/UploadPage.tsx`, `frontend/src/components/AddRecordPage.tsx`
- **Verification:** `grep -rn "<main" src` returns only `App.tsx` and `LoginGate.tsx`; no test asserted `role="main"` on either page; full suite green; `tsc -b --noEmit` and `oxlint` exit 0.
- **Committed in:** `62c5829` (Task 1 commit)
