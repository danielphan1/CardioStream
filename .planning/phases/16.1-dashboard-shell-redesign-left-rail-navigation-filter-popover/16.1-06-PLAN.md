<objective>
Wire the shell (UI-SPEC §5.0/§5.1/§5.2): replace the three duplicated per-view header blocks in `App.tsx` with one `AppShell` wrapper that mounts exactly one shell per breakpoint, holds the single `openOverlay` state, measures one shared top band, reassigns `inert` to the rail, and gives the Command Bar `data-surface="panel"`. Then delete `Header.tsx` and fix the five guide/banner strings that now point at a header which no longer exists (§6.1).

Purpose: This is the commit where the 216px horizontal header band stops existing and the redesign becomes visible. The `inert` reassignment is the load-bearing part: §5.0 records that today's `inert={guideOpen}` sits on **two** elements per view — the header wrapper and `<main>` — and deleting the wrapper without moving its attribute would reintroduce, on the one surface this phase creates, exactly the defect `App.tsx`'s existing comment documents. The rail is not inside `<main>` and cannot inherit it.

Output: `App.tsx` routes all four views through `AppShell`; `Header.tsx` and `Header.test.tsx` are gone with their assertions already re-homed in plans 16.1-03 and 16.1-05; no user-facing string points at a header any more.
