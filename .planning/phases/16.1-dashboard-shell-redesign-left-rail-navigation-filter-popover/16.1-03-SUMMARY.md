## The two things that were easy to get wrong

**1. `includeGuide` is a client decision, not a style choice.** `ShellNav({ onNavigate, includeGuide = true })`. The rail leaves the default; the nav panel will pass `false`. Below 1024px `ShellNav` renders only inside the nav panel, so a Guide in the utility group would make Menu → Guide the only route to the Guide — producing `guideOpen && openOverlay === "nav"` simultaneously, where `NavPanel` (later in tree order, both `fixed z-50`) paints over `GuideOverlay` and tapping Guide appears to do nothing. Independently, `GuideOverlay.tsx:159` restores focus via `document.getElementById("guide-toggle-button")`, which would not exist with the panel closed, breaking the voice-opened guide path (`lib/agent.ts:173`) by dropping focus to `<body>`. The reasoning is recorded in the prop's JSDoc so plan 05 cannot re-litigate it by accident. Two tests pin it: exactly one `#guide-toggle-button` at the default, zero under `includeGuide={false}` with Theme / Voice Replies / Log out all still present.

**2. `LogoutConfirmDialog` keeps its focus trap — it is the app's one true modal.** Extracted verbatim: 84 lines, byte-identical apart from the added `export` (`diff` of the function range against `8bcb3cd:frontend/src/components/Header.tsx` reports only the signature line). `Header.test.tsx` needed no change and still passes 5 tests. `useDismissable` deliberately traps nothing and carries `GuideOverlay`'s rationale across in a header comment, so the mic stays Tab-reachable (D-03/D-04). No trap was added anywhere else and none was removed.

## Accessibility

All eight `ShellNav` controls carry `min-h-12` (asserted by a floor test counting 8 buttons), are icon + text (never icon-only), left-aligned, and reachable by keyboard. Colours are all `var(--…)` tokens. `useDismissable` traps no focus and removes its window-level `Escape` listener on close and on unmount, so no surface can strand keyboard focus or leave a dangling global handler (T-16.1-09). `aria-pressed` plus the label text carries utility state; utilities are never accent-filled.
