<interface_contract>
Every chart component exports a default React component with props:
- `BPTimeline`, `PulseTrend`, `AmPmComparison`: `{ readings: Reading[]; variant: "hero" | "mini" }`
- `CategoryBars`: `{ stats: StatsSummary; variant: "hero" | "mini" }`

Variant semantics (RESEARCH Pattern 4 / Pitfall 8, UI-SPEC mini rules):
- `hero`: full interactivity — `accessibilityLayer` on (Recharts 3 default), `<Tooltip trigger="click">`, axes with 16px ticks, line-end/reference labels.
- `mini`: `accessibilityLayer={false}`, NO Tooltip, axes/ticks/labels hidden entirely — a live preview inside a parent `<button>` (plan 02-07 supplies the button and pointer-events handling).

All charts render inside `<ResponsiveContainer width="100%" height="100%">` — the PARENT supplies fixed height (hero h-[420px], mini h-36 in 02-07; Pitfall 2). Colors come exclusively from CSS vars (`var(--line-systolic)`, `categoryColor(...)`) so both themes work with zero chart code changes.
</interface_contract>
