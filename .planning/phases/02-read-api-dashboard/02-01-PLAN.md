<interface_contract>
Response shapes the frontend (plan 02-02 `api/types.ts`) mirrors — keep these exact:

- `ReadingOut` JSON keys: `id`, `datetime` (naive ISO, e.g. "2025-02-22T11:26:00"), `systolic`, `diastolic`, `pulse`, `am_pm`, `bp_category`, `pulse_category`, `map` (float), `pulse_pressure`, `notes` (nullable).
- `StatsSummary` JSON: `{ count: int, systolic: {avg, min, max} | null, diastolic: {avg, min, max} | null, pulse: {avg, min, max} | null, categories: [{category, count, percent}] (always all 6, clinical order), latest_reading: str | null }`. `avg` rounded to 1 decimal. Vitals objects are null when count == 0; category percents are 0.0 then.
- Canonical BP labels (verbatim from derivations.py, spaces included): "Hypotension", "Normal", "Elevated", "Stage 1", "Stage 2", "Hypertensive Crisis". Clinical order = that exact sequence.
- Query params: `start_date`/`end_date` (ISO date), `am_pm` (Literal "AM"/"PM"), `bp_category` (Literal of the six labels). All optional; end_date is INCLUSIVE.
</interface_contract>
