# Phase 2 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Theme in one sentence (from 02-CONTEXT.md): **a calm coastal instrument panel — pastel ocean canvas, navy ink, clinical severity colors where health meaning lives, a hint of sail in the chrome.**
>
> Governing accessibility floor (CLAUDE.md, non-negotiable): all interactive targets ≥48px, body text ≥18px, high contrast everywhere information lives, keyboard navigable with visible focus, no drag / hover-only / precision interactions.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — Tailwind CSS 4 CSS-first design tokens (`@theme` + CSS custom properties) |
| Preset | not applicable |
| Component library | none (hand-built accessible controls per 02-RESEARCH.md architecture) + react-day-picker 9 for the calendar |
| Icon library | lucide-react (tree-shaken imports only: `Sailboat`, `Sun`, `Moon`, `CalendarDays`, `X`, `ChevronDown`) |
| Font | Atkinson Hyperlegible, self-hosted via `@fontsource/atkinson-hyperlegible` (weights 400 + 700); fallback stack `system-ui, -apple-system, "Segoe UI", sans-serif` |

**Why no shadcn** (decision, not omission): CLAUDE.md locks the stack with "do not substitute" and specifies Tailwind 4 as the styling layer with hand-rolled controls; 02-RESEARCH.md's verified architecture (segmented button groups, chips, react-day-picker, Recharts-native a11y) needs no Radix/Base-UI primitives — this phase has zero popovers/menus/dialogs beyond the calendar, which react-day-picker covers. `frontend/` does not exist yet; it is scaffolded this phase with these tokens from the first commit.

**Why this font**: privacy constraint bans third-party requests (SEC-03 discipline), so no Google Fonts CDN — `@fontsource` self-hosts. Atkinson Hyperlegible is purpose-designed for low-vision legibility (distinct letterforms at the sizes this dashboard uses) and ships only 400/700, which enforces the two-weight contract below.

## Spacing Scale

Declared values (8-point scale, all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, chip inner vertical padding |
| sm | 8px | Gaps inside button groups, table cell inner padding, tooltip row spacing |
| md | 16px | Default gap between controls, card inner padding, filter-bar item gaps |
| lg | 24px | Section padding, stats-tile inner padding, gap between mini-chart cards |
| xl | 32px | Vertical rhythm between page sections (header → filter bar → stats strip → hero → minis → table) |
| 2xl | 48px | Minimum interactive target height/width (buttons, chips, toggle, calendar day cells, tooltip Close, "Show 20 more") |
| 3xl | 64px | Page gutter on wide screens, hero-chart section breathing room |

Exceptions (documented, per 02-RESEARCH.md Pitfall 14):
- **Chart data dots are NOT 48px targets** — dots render at r=5 (10px), activeDot r=10 (20px). ACC-01's 48px floor applies to *controls*; point inspection satisfies the no-precision rule via three redundant paths: Recharts nearest-point hit detection (click anywhere near a point works), keyboard arrow navigation (`accessibilityLayer`), and the readings table as the zero-precision fallback. Record this rationale in the plan so verification does not flag dots.
- Chart axis tick text renders at 16px (see Typography exception).

## Typography

| Role | Size | Weight | Line Height | Used for |
|------|------|--------|-------------|----------|
| Body | 18px | 400 | 1.5 | Table cells, filter-state sentence, empty/error body copy, tooltip rows, chip labels |
| Label | 20px | 700 | 1.2 | Button labels, chart line-end labels (D-07), stats-tile captions, table headers, mini-card titles |
| Heading | 24px | 700 | 1.2 | Hero chart title, section headings ("Readings", empty-state heading) |
| Display | 32px | 700 | 1.2 | "Chris's Health Dashboard" header, stats-tile values (avg/min/max numbers) |

Rules:
- Exactly these 4 sizes and 2 weights (400, 700 — Atkinson Hyperlegible ships no 600). No other size/weight anywhere in this phase.
- 18px is the floor — nothing readable renders smaller, with one declared exception: **hero-chart axis tick text at 16px weight 400** (supplementary graphic annotation, not body text; every value the ticks approximate is available at ≥18px in the tooltip and readings table). Mini charts hide axes, ticks, tooltips, and labels entirely (they are previews inside a single button).
- Line-end labels on the BP Timeline (D-07: "Systolic" / "Diastolic") render at 20px weight 700 in the line's own color — this is why line colors below must clear 4.5:1, not just the 3:1 graphics floor.

## Color

### 60/30/10 — Light theme ("airy nautical", default)

| Role | Value | Contrast (computed 2026-07-14) | Usage |
|------|-------|-------------------------------|-------|
| Dominant (60%) | `#F2F7F5` foam | — | Page background |
| Secondary (30%) | `#E2EDF2` pale sky | ink on it: 13.41:1 | Cards (stats tiles, mini-chart cards, table container, filter bar surface) |
| Ink (text) | `#14213D` navy | 14.76:1 on foam | ALL text, icons, borders — navy carries information (D-13) |
| Accent (10%) | `#14213D` navy fill, white text | white on navy: 15.97:1 | See reserved list below |
| Focus ring | `#1D4E89` marine blue | 7.75:1 vs foam | 3px `focus-visible` ring + 2px offset on every interactive element |
| Destructive | none this phase | — | No destructive actions exist in Phase 2 |

**Accent (filled navy) reserved for exactly:** active date-preset button (D-17), active AM/PM segment, active category chip, "Show all data" button (D-11), "Show 20 more" button (D-23), tooltip Close button, calendar selected-day cell. Nothing else gets a navy fill — inactive controls are pale-sky cards with navy text and a 2px navy border.

### 60/30/10 — Dark theme ("night sea")

| Role | Value | Contrast | Usage |
|------|-------|----------|-------|
| Dominant (60%) | `#0B1626` navy-black | — | Page background |
| Secondary (30%) | `#13233A` deep sea | text on it: 13.74:1 | Cards, filter bar surface |
| Ink (text) | `#E8F1EF` pale foam | 15.78:1 on background | All text, icons, borders |
| Accent (10%) | `#8FC1D4` pastel sky fill, `#0B1626` text | 9.29:1 | Same reserved-for list as light theme |
| Focus ring | `#8FC1D4` | 8.4:1 vs background | Same ring pattern |

Theme mechanics (D-15, verified in 02-RESEARCH.md): Tailwind 4 `@custom-variant dark (&:where(.dark, .dark *));`, `.dark` class on `<html>`, persisted to localStorage, toggled by a ≥48px labeled button ("Light" / "Dark" text + Sun/Moon icon — never icon-only) in the header. All chart colors are CSS custom properties so Recharts SVG flips with the class (`stroke="var(--line-systolic)"`).

### Chart data colors (both themes)

| Series | Light | Dark | Contrast vs surface |
|--------|-------|------|---------------------|
| Systolic line + dots + end label | `#1D3557` | `#A8CBEA` | 11.42:1 / 10.71:1 |
| Diastolic line + dots + end label | `#26707D` | `#6FC7C4` | 5.25:1 / 9.2:1 |
| Pulse line + dots | `#1D3557` | `#A8CBEA` | (single-series chart, reuse systolic navy) |
| Bradycardia reference line (60 bpm) | `#4A6B8A` dashed `6 4`, labeled "60 bpm — Bradycardia" at the right edge, 16px | `#8FB3D1` | 5.16:1 / 8.24:1 |
| AM bars (AM vs PM chart) | `#1D3557` | `#A8CBEA` | as above |
| PM bars (AM vs PM chart) | `#26707D` | `#6FC7C4` | as above |

Systolic vs diastolic differ in both hue and lightness (color-blind safe) and are always disambiguated by the D-07 text labels — color is never the sole channel.

### Clinical category colors (D-14 — severity semantics, ocean-harmonized)

Single source of truth: `frontend/src/lib/palette.ts` maps the six canonical labels (verbatim from `backend/app/derivations.py`) to CSS vars consumed by chips, category bars, AND timeline bands — never three separate color lists.

| Category | Light fill | White text on it | Fill vs foam | Dark fill (text `#0B1626`) | Dark ratios |
|----------|-----------|------------------|--------------|---------------------------|-------------|
| Hypotension | `#4A6B8A` blue-grey | 5.58:1 | 5.16:1 | `#8FB3D1` | 8.24:1 |
| Normal | `#2F7D5C` sea green | 4.99:1 | 4.61:1 | `#63C68F` | 8.65:1 |
| Elevated | `#8F6A00` deep amber | 4.97:1 | 4.59:1 | `#E0B84E` | 9.62:1 |
| Stage 1 | `#B34700` deep orange | 5.5:1 | 5.08:1 | `#EE9B57` | 8.18:1 |
| Stage 2 | `#B3261E` deep red | 6.54:1 | 6.04:1 | `#EF7B70` | 6.69:1 |
| Hypertensive Crisis | `#7F1D1D` darkest red | 10.02:1 | 9.26:1 | `#F2564D` | 5.37:1 |

Usage rules:
- **Chips** (table, category filter): solid category fill, white text (light) / `#0B1626` text (dark), 20px label, ≥48px tap height for the filter chips; table chips are display-only (not interactive) and may be shorter.
- **Category bars** (DASH-03): solid category fill, bar label outside the bar in ink color ("Stage 1 — 34 readings (26%)" per D-10) so text never sits on mid-contrast fills.
- **Timeline bands** (D-08): same vars at `fillOpacity 0.10` (light) / `0.14` (dark), each with a small 14px edge label in the category's solid color at the left inside edge — bands are ambient context and explicitly exempt from contrast floors (decorative tint; the authoritative category is in the tooltip and chip). Bands render BEFORE `<Line>` elements (Recharts 3 z-order = JSX order).
- Band y-spans use systolic thresholds: 40–90 Hypotension, 90–120 Normal, 120–130 Elevated, 130–140 Stage 1, 140–180 Stage 2, 180–220 Crisis (02-RESEARCH.md Assumption A1 — confirm at first visual demo).

All ratios above computed with the WCAG 2.x relative-luminance formula on 2026-07-14; every text pair clears 4.5:1 AA at any size, every graphic clears 3:1. Re-verify with WebAIM during the phase-gate contrast audit and record final ratios (ACC-01 evidence).

### Fixed axis bounds (D-05 discretion, resolved)

| Chart | Y domain | Ticks |
|-------|----------|-------|
| BP Timeline (+ AM/PM BP bars) | [40, 220] mmHg | 40, 90, 120, 130, 140, 180, 220 (AHA thresholds) |

Never auto-fit. Verified coverage: seeded data spans systolic 60–211, diastolic 42–129, pulse 42–69.

## Copywriting Contract

Voice: calm, first-person-neutral, no medical interpretation ever (out-of-scope table bans alarm language). Sentence case everywhere; no exclamation marks; dates written like "June 13, 2025".

| Element | Copy |
|---------|------|
| Primary CTA (empty state, D-11) | "Show all data" |
| Table CTA (D-23) | "Show 20 more" (hidden when all rows shown; replaced by "Showing all {n} readings" in 18px body text) |
| Page header (DASH-11) | "Chris's Health Dashboard" (with Sailboat icon mark, `aria-hidden="true"`) |
| Filter-state sentence (D-20) | Reads left-to-right like a sentence: "{Last 30 days · to Jun 13, 2025} · {AM} · {All categories}" — always visible in the filter bar |
| Date preset labels (D-17) | "7 days" / "30 days" / "90 days" / "All" + a "Custom…" affordance opening the From/To fields |
| Empty state heading (D-11) | "No readings match these filters" |
| Empty state body (D-11) | "There are no {AM} readings in {this date range}{ in {category}}. The newest reading is from {June 13, 2025}." + accent button "Show all data". Never auto-widen the chosen range. |
| Error state (API unreachable/failed) | Heading: "Couldn't load the readings" · Body: "The dashboard couldn't reach the data server. It will keep retrying — or press Try again." + accent button "Try again" (triggers TanStack Query refetch). Never show raw error text, status codes, or stack traces. |
| Loading state | Skeleton tiles/chart area with `aria-busy="true"`; after first load, filter changes use `keepPreviousData` (no blank flash, no spinner) |
| Mini-card accessible labels | `aria-label="Show {chart name} chart"` — visible 20px title on each mini card: "Blood Pressure" / "Pulse" / "BP Categories" / "AM vs PM" |
| Tooltip (D-09) | Title "{June 3, 2025 · 7:42 AM}", rows "BP 128 / 74", "Pulse 58", category chip; ≥48px "Close" button; also dismisses on Escape |
| Destructive confirmation | none — Phase 2 has no destructive actions |

Date presets anchor to the newest reading (`latest_reading` from `/stats/summary`), per 02-RESEARCH.md Open Question 1 recommendation — the filter-state sentence must say so honestly ("to Jun 13, 2025"), which is the copywriting half of that decision.

## Layout & Interaction Contract

Vertical order (locked by D-20/D-22, discretion resolved for below-fold):

1. **Header** — Sailboat mark + "Chris's Health Dashboard" (Display 32px) + theme toggle, on foam; wave-curve SVG divider below (single-color `#E2EDF2` / `#13233A` path, `aria-hidden`, decorative only per D-16)
2. **Filter bar** — pale-sky surface: date-preset segmented row, Custom From/To (react-day-picker popover, ≥48px day cells, typed `YYYY-MM-DD` entry kept alongside), `[All | AM | PM]` segment, category chip row, filter-state sentence; wraps on narrow screens
3. **Stats strip** — pale-sky tiles rendering the full `/stats/summary` payload (D-21): 3 vitals × avg/min/max (Display values, Label captions), reading count, % per category
4. **Hero chart** — `h-[420px]`, full interactivity (accessibilityLayer, click-persist tooltip)
5. **Mini row** — three live mini cards (`h-36`, single `<button>` each, whole card is the ≥48px target, `accessibilityLayer={false}`, no Tooltip, `pointer-events:none` on inner SVG)
6. **Readings table** — newest-first, 20 rows + "Show 20 more" (+20 increment); columns Date, Time, AM/PM, "128 / 74", Pulse, category chip; Notes row only when present

Motion (D-04 discretion resolved): hero/mini swap = 250ms opacity + scale CSS transition, `ease-in-out`, on the two affected slots only; `motion-reduce:transition-none` makes it instant. Recharts `isAnimationActive={!prefersReducedMotion}`.

Responsive breakpoints (discretion resolved): single column throughout; minis 3-across ≥768px, stacked below; filter bar wraps to multiple rows below 768px; page gutter 16px (<768px), 32px (768–1279px), 64px (≥1280px). No layout requires precision or horizontal scrolling.

Focus & keyboard: every control shows the 3px focus ring; tab order follows the vertical order above; each chart is one tab stop with arrow-key point navigation (Recharts 3 default); no hover-only information anywhere (tooltips are `trigger="click"`).
