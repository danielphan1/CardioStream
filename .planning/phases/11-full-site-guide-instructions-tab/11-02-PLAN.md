button) build against: a new `store/guide.ts` (ephemeral `open`/`setOpen`/`toggleOpen`, mirroring

until billing is live per project-wide accepted condition) or a future non-guide command reaches
the guide's visibility state. Getting the store's action names and the D-07 auto-close discipline
exactly right here — independently unit-tested — prevents rework downstream.
Output: `useGuide` (open + setOpen/toggleOpen), `AppliedFilters.guideOpen`, and
`applyAgentFilters`'s guideOpen branch + D-07 auto-close check, all independently unit-tested.
