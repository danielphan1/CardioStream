`onSuccess` callback to each of the three existing `useMutation({ mutationFn: ... })` calls:

["incidents"]`, `useCreateProcedure` invalidates `queryKey: ["procedures"]` — each via `const qc

qc.invalidateQueries({ queryKey: [...] })` added to the `useMutation` call, so a caregiver's
newly submitted record surfaces in the overlay immediately instead of waiting out the
5-minute staleTime (addresses 09-CONTEXT.md's staleTime discretion item).
