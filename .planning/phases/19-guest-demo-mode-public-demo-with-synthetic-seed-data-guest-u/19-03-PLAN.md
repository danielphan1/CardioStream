<objective>
Generate and commit synthetic data for the three tables that have never had any synthetic data —
labs, incidents, procedures — using a seeded-deterministic generator script, and pin its character
with a dedicated regression test.

Purpose: `backend/scripts/generate_sample.py` covers `readings` ONLY. Per D-05, the user explicitly
asked for labs/incidents/procedures synthetic data too, committed in the repo, so BOTH the hosted
guest demo AND anyone who clones the repo and runs a local install see a fully populated dashboard
across all four data types. Per 19-RESEARCH.md, these three tables are POST-body-shaped (created via
`LabResultCreate`/`IncidentCreate`/`ProcedureCreate`, never via a spreadsheet import) — the "mirror
generate_sample.py" instruction from CONTEXT.md means matching its DISCIPLINE (seeded RNG, explicit
synthetic-only framing, character-coverage self-check, byte-identical reruns), not its `.xlsx`/pandas
machinery, which does not apply to data that was never spreadsheet-shaped.
Output: `backend/scripts/generate_demo_records.py`, the committed `backend/sample_data/demo_records.json`
it produces, and `backend/tests/test_demo_records_sample.py` pinning its shape.
</objective>
