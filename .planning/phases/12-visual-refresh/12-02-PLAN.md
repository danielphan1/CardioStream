<objective>
Apply the D-05 depth treatment (rounded-lg → rounded-xl, add `shadow-[var(--shadow-elevation)]`) and the
D-06 type-scale formalization (rename ad-hoc `text-xl`/`text-[2rem]`/`text-2xl` to the new named
`--text-control`/`--text-h1`/`--text-h2` tokens, at unchanged rendered sizes) to the four
data-surface/feedback components RESEARCH.md and PATTERNS.md identify as the canonical "flat card" targets:
`StatsStrip.tsx` (RESEARCH.md's own cited before/after example), `ChartTooltip.tsx` (the one existing
`shadow-lg` precedent, now joining the same themed mechanism as everything else), `EmptyState.tsx`, and
`ReadingsTable.tsx`. It also closes a plan-checker-flagged gap in `App.tsx`: the dashboard's own error-retry
panel, its `ChartSkeleton` loading placeholders, and its "Readings" section heading were left on the old
`rounded-lg`/`text-2xl` treatment because CONTEXT.md's Integration Points list scoped only to
`frontend/src/components/` and never named `App.tsx` itself — this plan absorbs that fix since it already
owns the dashboard hero surfaces (StatsStrip/ReadingsTable) that sit directly adjacent to these App.tsx
elements in the steady-state view.

This plan depends on 12-01 because every edit here consumes tokens (`--shadow-elevation`, `--text-h1`,
`--text-control`, `--text-h2`) that plan defines — it cannot run before 12-01 lands. It has zero file overlap
with 12-03 through 12-07, so it executes in parallel with them once 12-01 is done.

Purpose: these four components are the first thing Chris/a caregiver sees on the dashboard (stats tiles,
tooltip, empty state, data table) — landing the depth/type-scale treatment here first establishes the
visual pattern the remaining Wave 2 plans replicate. Task 3 additionally closes App.tsx's steady-state
chrome (error panel/loading skeleton/heading) so no dashboard-visible surface is left on the old treatment,
and applies D-05's spacing-rhythm sub-decision ("more breathing room between sections") to App.tsx's
ChartSkeleton wrapper.
Output: four components with rounded-xl + shadow depth and formalized type-scale classes, zero rendered-size
or accessibility-floor change, plus App.tsx's error panel/skeleton/heading brought to the same standard with
its skeleton section-level gaps bumped from gap-6 to gap-8.
</objective>
