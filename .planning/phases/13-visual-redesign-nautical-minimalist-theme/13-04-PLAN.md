<objective>
Give the Command Bar the new "contrasting feature panel" identity `13-UI-SPEC.md` §Component Language item 3 calls for — reusing `var(--color-depth)` as its background (App.tsx's wrapper band) instead of `var(--color-mist)` like every other surface, since DESIGN.md already names the Command Bar "the app's one truly distinctive component" and it is the product's core value proposition (voice-first input). Re-skin the rest of `App.tsx` (Dashboard skeleton/error states, ReadingsTable section heading, Upload/Records view backgrounds) to the new tokens in the same pass since both files are edited together by design (this specific design decision spans both files, per `13-PATTERNS.md`'s explicit flag). Also thread a `readings` prop into the `<StatsStrip>` call site so Plan 13-11 (Wave 3, depends on this plan) can build its new sparkline sub-component without a second pass over `App.tsx`.

Purpose: because CommandBar's background is switching from an inherited light Mist band to a dark Depth band, every piece of text/border inside CommandBar that currently has NO independent chip background (relies on inheriting the light band behind it) would become illegible without an explicit flip — this plan works out and applies that flip precisely, using only already-WCAG-verified token pairs.
Output: App.tsx and CommandBar.tsx fully re-skinned; CommandBar reads as a deliberate dark instrument panel in both themes with legible text throughout; StatsStrip's call site is ready for Plan 13-11.
</objective>
