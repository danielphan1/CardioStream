<objective>
Replace the entire Phase 12 design-token layer in `frontend/src/index.css` with the Phase 13 "Slack Water" (light) / "Night Watch" (dark) token set locked in `13-UI-SPEC.md`, and update the WCAG contrast regression test to match. This is the single integration point every other Wave-2 plan depends on — no component file is touched here, only the token source of truth.

In addition to the token map `13-UI-SPEC.md` lists verbatim, this plan introduces one pair of tokens not in that map: `--color-panel` / `--color-panel-text` — a dedicated, non-inverting background/text pair for the Command Bar's "one dark, contrasting feature panel" identity (D-04). `--color-depth` is unsuitable for this because it is the ink/text token, which *inverts* per theme by design (dark navy in light theme, near-white in dark theme) — reusing it as a panel background would make the panel correctly dark in light theme but incorrectly the single brightest surface on the page in dark theme, defeating the "dark instrument panel in both themes" intent. `--color-panel`/`--color-panel-text` are defined here so Plan 13-04 has a real, contrast-verified, always-dark/always-light pairing to consume instead.

Purpose: every subsequent plan's `var(--color-*)`/`text-*`/`rounded-xl`/`shadow-[var(--shadow-elevation)]` references must resolve to real, contrast-verified Phase 13 values the moment they land, with zero flag-day coordination required.
Output: `frontend/src/index.css` fully replaced; `frontend/src/tests/contrast.test.ts` updated and passing.
</objective>
