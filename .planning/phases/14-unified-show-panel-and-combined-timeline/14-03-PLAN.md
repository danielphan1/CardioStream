<objective>
Grow the agent command vocabulary from three dataset tokens to five and add a `show_only` action
carrying a list of datasets.

Purpose: "**only** see the blood pressures **and** pulses" is a two-dataset *exclusive* command.
`ToggleDataset` takes exactly one dataset plus an explicit on/off and is single-valued by a
deliberate Phase 9 decision, so it physically cannot express the first example the client gave.
Output: closed-union schema, prompt, confirmation copy, dispatch, and tests.
</objective>

<task name="schema_tokens_and_show_only">
  <read_first>
    - backend/app/agent/schemas.py (DatasetToken, ChartToken, ToggleDataset, AgentOutput union, `_lower_tokens` / `_lower_value`, AppliedFilters)
    - CLAUDE.md (structured-outputs caveats — no numeric min/max in the schema)
  </read_first>
  <action>
    1. `DatasetToken` becomes `Literal["blood_pressure", "pulse", "labs", "incidents", "procedures"]`.
    2. `ChartToken` becomes `Literal["timeline", "bp_categories", "am_pm_comparison"]` — `bp_timeline`
       and `pulse_trend` are no longer charts, they are dataset toggles.
    3. New model:
       `class ShowOnly(BaseModel)` with `action: Literal["show_only"]` and `datasets: list[DatasetToken]`.
    4. Add `ShowOnly` to the `AgentOutput.result` union.
    5. `AppliedFilters`: rename `activeChart` → `chartView` (type `ChartToken`), keep
       `overlayDataset`/`overlayState` but note they now accept all five tokens, and add
       `showOnly: list[DatasetToken] | None = None`.

    **`_lower_value` must learn to handle lists.** It currently recurses into `str` and `dict` only,
    so a `datasets` list would bypass the case-normalisation the structured-outputs docs require
    (enum values must be compared case-insensitively). Add a `list` branch that maps `_lower_value`
    over the items.

    Do NOT add `minItems`/`maxItems` to the schema — constrained sampling does not support numeric
    bounds. Validate emptiness locally after parse instead (next task).
  </action>
  <acceptance_criteria>
    - `DatasetToken` has exactly five members; `ChartToken` has exactly three
    - `ShowOnly` is a member of the `AgentOutput.result` union
    - `_lower_value` recurses into lists — `_lower_value("datasets", ["Blood_Pressure"])` returns `["blood_pressure"]`
    - `AppliedFilters` exposes `chartView` and `showOnly`; `activeChart` no longer exists
    - No `minItems` / `maxItems` / `ge` / `le` anywhere in the Claude-facing models
  </acceptance_criteria>
</task>
