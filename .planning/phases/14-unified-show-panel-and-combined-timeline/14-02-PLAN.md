<objective>
Fold `activeChart` (single-select) and `overlayDatasets` (multi-select) into one `visibleDatasets`
five-key map plus a separate `chartView`, with a migration for already-persisted filter blobs.

Purpose: the split between a radio-style chart picker and a checkbox-style overlay row is the root
cause of the client complaint. `store/filters.ts` is explicitly THE agent command schema, so this
shape change is the load-bearing one — every other plan in the phase consumes it.
Output: new store shape, tests, and a migration that preserves date/AM-PM/category across upgrade.
</objective>
